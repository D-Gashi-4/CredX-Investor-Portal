# CredX Investor Portal

A polished static investor dashboard prototype for monitoring portfolio performance, deal flow, and allocations.

## Included

- Hero section and investor-facing overview
- KPI cards for return, liquidity, pipeline, and risk
- Opportunity pipeline with featured deals
- Allocation panels and activity feed
- Responsive layout for desktop and mobile

## Open locally

Open `index.html` in a browser, or serve the folder with a lightweight HTTP server.

Example:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.
